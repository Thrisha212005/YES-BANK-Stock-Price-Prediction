# YES BANK Stock Price Prediction – EDA & Machine Learning

## Project Overview
This project analyses historical YES BANK stock prices using Exploratory Data Analysis (EDA) and Machine Learning techniques to understand stock trends, returns, volatility, and predict future closing prices.

## Objectives
- Analyse historical stock price trends.
- Study monthly returns and volatility.
- Explore relationships between stock price variables.
- Predict the next month's closing price using machine learning.

## Dataset
- Historical monthly stock data from July 2005 to November 2020.
- 185 records containing Open, High, Low, and Close prices.

## Exploratory Data Analysis
- Stock price trends and distributions.
- Monthly returns and volatility.
- Correlation analysis.
- Statistical hypothesis testing.

## Machine Learning Models
- Baseline Model
- Linear Regression
- Decision Tree
- Random Forest
- Support Vector Regression (SVR)

## Technologies Used
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Google Colab.

## Files
- EDA Notebook – Data exploration and visualisation.
- ML Notebook – Model building, evaluation and prediction.
- Trained model files (.pkl), if included.
- Project presentation.

## Conclusion
The project compares multiple machine learning models to predict YES BANK's next-month closing stock price. SVR achieved the best RMSE among the machine learning models tested.
